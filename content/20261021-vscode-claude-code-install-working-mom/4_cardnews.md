# 인스타그램 카드뉴스 (7장)

## 1장 · 표지 (후크)
- 메인: 깃허브 '비공개' 눌렀다가 화면 깨진 사람? 🙋‍♀️
- 서브: 컴퓨터 까막눈 46세 워킹맘의 VS Code·클로드 코드 설치기
- 상단 라벨: AI 자동화 도전기 1탄
- 디자인: 다크 배경 + 깜빡이는 커서 일러스트, 오른쪽 아래 놀란 표정 엄마 캐릭터

## 2장 · 첫 만남
- 메인: 까만 화면 = 개발자 전용?
- 서브: 터미널은 마우스 대신 '글자로 부탁하는 창'이에요.
  VS Code에서 Ctrl + ` 누르면 열려요.
- 디자인: 터미널 캡처(경로·이름 가림) + "무서워하지 마세요" 말풍선

## 3장 · 설치 체크 칸
- 메인: 체크 칸 5개, 이것만 기억!
- 서브:
  ✅ PATH에 추가 → 꼭 켜기
  ✅ 'Code(으)로 열기' 2개 → 기본 꺼짐, 직접 켜기
  ✅ 편집기로 등록 → 기본값(켜짐) 그대로 OK
- 디자인: 실제 설치 화면을 단순화한 체크리스트, 초록 체크·회색 빈칸 대비

## 4장 · 클로드 코드 로그인
- 메인: 로그인 눌렀는데 브라우저가 열려요?
- 서브: 정상이에요! 내 Claude 계정으로 로그인 → '승인' → VS Code로 복귀
  (유료 요금제 필요, 주소가 공식 도메인인지 확인)
- 디자인: VS Code → 브라우저 → VS Code 세 단계 화살표 도식

## 5장 · 화면 깨짐 해프닝
- 메인: 비공개로 했더니 글자만 줄줄이 😱
- 서브: 무료 깃허브는 '공개' 저장소에서만
  웹페이지(GitHub Pages)를 띄울 수 있어요.
- 디자인: 디자인 없이 글자만 나열된 화면 일러스트 + 자물쇠 아이콘, 빨간 경고 띠

## 6장 · 해결 & 완성
- 메인: 보여 줄 것은 공개, 숨길 것은 비공개
- 서브: 리모컨 페이지만 공개 저장소로 분리했더니
  폰 홈 화면에 나만의 AI 리모컨 완성 🎉
- 디자인: 공개 상자(index.html) / 비공개 상자(원고·전략) 두 칸 비교 + 스마트폰 목업

## 7장 · 저장 · 공유 · 팔로우
- 메인: 설치할 때 다시 보려면 📌 저장!
- 서브: AI 자동화 해 보고 싶은 친구에게 공유해 주세요.
  2탄 '회사-집 컴퓨터 맞추다 만난 빨간 에러'가 궁금하면 팔로우!
- 디자인: 상단 저장(북마크)·공유(종이비행기) 아이콘, 하단 프로필 핸들 + 팔로우 버튼

## 피드 캡션
검은 화면만 봐도 손이 떨리던 46세 워킹맘의 첫 설치 기록 📝
체크 칸, 로그인 승인, 깃허브 화면 깨짐까지 제가 헤맨 곳만 모았어요.
설치하실 때 꺼내 보시게 저장해 두세요 💛
자세한 설정법은 프로필 링크(케이맘픽스)에 정리해 두었어요.
