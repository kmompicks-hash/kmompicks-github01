[ 체크 칸 다섯 개 앞에서 한참 멈춤 ]

설치하다 보면 '추가 작업 선택'이라고
네모 칸이 잔뜩 나와요.

😵 번역 말투라 더 어렵게 느껴지죠 ㅜㅜ

제가 고른 방법은 이거예요.

✔ PATH에 추가 → 무조건 켜 두기
✔ 'Code로 열기' 두 개 → 켜면 편해요
✔ 바탕화면 아이콘 → 마음대로
✔ 편집기로 등록 → 기본값 그대로 OK

💡 '상황에 맞는 메뉴'라는 말은
그냥 마우스 오른쪽 클릭 메뉴래요.

알고 나니 웃음이 나더라구요 ㅎㅎ

[가운데] [이미지: images/naver-02-checkbox.png]


[ 로그인 눌렀는데 인터넷 창이 열려요? ]

다음은 AI 비서 '클로드 코드'예요.
확장 메뉴에서 찾아 설치했어요.

✅ 만든 곳이 Anthropic인지 꼭 확인하세요!

로그인을 누르니까
갑자기 인터넷 창이 휙 열리는 거예요.

😅 순간 뭘 잘못 누른 줄 알았어요.

[가운데] 원래 그렇게 하는 거래요!

인터넷 창에서 제 클로드 계정으로
로그인하고 '승인'을 눌렀더니
프로그램 쪽도 바로 연결됐어요.

⚠️ 참고로 클로드 코드는
유료 요금제가 있어야 쓸 수 있어요.

저는 미리 확인하고 시작했답니다.

보관함 만들 때 '공개'랑 '비공개' 중에

[ 케이맘 딥픽 : 숨기면 왜 안 보일까? ]

🔍 너무 궁금해서 찾아봤어요.

무료 계정은 '공개' 보관함에서만
홈페이지 기능을 쓸 수 있대요.

홈페이지는 원래 모두가 보는 거라
무료로는 공개가 기본인 거죠.

💰 비공개로 띄우려면 유료래요.

[가운데] 제가 오해했던 것들도 있었어요

❌ 하나 공개하면 내 계정 다 공개된다
⭕ 보관함마다 따로 정할 수 있어요

❌ 페이지만 보이고 파일은 숨겨진다
⭕ 공개 보관함은 안의 파일이 다 보여요

🔐 그래서 저희 집은 이렇게 나눴어요.
보여 줘도 되는 페이지 파일만 공개,
원고랑 블로그 전략은 비공개로요.
