## 사건 발생: 회사 PC에 Git이 없다?!

점심시간 짬을 내서 회사 컴퓨터의 VS Code를 열었는데, 소스 제어 탭에서 Git을 찾을 수 없다는 메시지가 떴어요.
집 컴퓨터에서는 잘 되던 게 회사에서는 안 되니 순간 머리가 하얘지더라고요.

알고 보니 이유는 단순했습니다. **VS Code는 Git을 '사용'하는 프로그램일 뿐, Git 자체는 따로 설치해야 해요.** 집 PC에는 예전에 깔아둔 Git이 있었고, 회사 PC에는 없었던 거죠.

### 해결: Git for Windows 설치

1. git-scm.com 에서 Windows용 Git 다운로드
2. 설치 옵션은 대부분 기본값(Next)으로 진행
3. 설치 후 **VS Code를 완전히 껐다가 다시 실행** (이걸 안 하면 여전히 Git을 못 찾는 경우가 있어요)

> 회사 PC는 보안 정책상 프로그램 설치가 막혀 있을 수 있어요. 설치 전에 사내 IT 규정을 꼭 확인하세요.

## 에러 폭탄: `error: no action specified`

Git을 설치했으니 이제 '내가 누구인지' Git에 알려줄 차례였어요. 블로그 글을 보고 아래 두 줄을 복사해서 터미널에 붙여 넣었습니다.

그런데 돌아온 건 빨간 글씨.

```
error: no action specified
```

무슨 뜻인지도 모르겠고, 회사 컴퓨터라 괜히 뭘 망가뜨린 건 아닌지 심장이 두근거렸어요.

### 원인: 두 줄의 명령어가 한 줄로 합쳐졌다

차분히 터미널을 다시 보니, 복사해 온 **두 줄의 명령어가 줄바꿈 없이 한 줄로 붙어서** 들어가 있었어요.
Git 입장에서는 명령어 두 개가 뒤섞인 이상한 문장 하나를 받은 셈이라, "그래서 뭘 하라는 거야?"라고 되물은 거죠.

**교훈: 터미널에 여러 줄을 한꺼번에 붙여 넣지 말 것.** 특히 웹페이지에서 복사할 때 줄바꿈이 사라지는 경우가 생각보다 흔해요.

---

## 해결: 한 줄씩, 천천히 다시 입력하기

한 줄 입력하고 Enter, 다음 줄 입력하고 Enter. 이렇게 천천히 다시 했더니 거짓말처럼 아무 에러 없이 끝났어요.

```
git config --global user.name "내이름"
git config --global user.email "내이메일@example.com"
```

에러가 안 났다고 끝이 아니라, 제대로 저장됐는지 확인까지 했습니다.

```
git config --global --list
```

목록에 `user.name`과 `user.email`이 보이면 성공이에요!

### 초보자를 위한 Git 초기 설정 팁 5가지

1. **명령어는 한 줄씩 입력하고 Enter** — 여러 줄 붙여넣기는 에러의 지름길이에요.
2. **이메일은 GitHub 가입 이메일과 똑같이** — 그래야 GitHub에서 내 작업 기록(커밋)이 내 계정으로 연결돼요.
3. **이름에 띄어쓰기가 있으면 큰따옴표(" ")로 감싸기**
4. **`--global`의 의미** — 이 컴퓨터 전체에 적용된다는 뜻이라 PC당 한 번만 해두면 돼요. 회사 PC, 집 PC 각각 한 번씩!
5. **에러 메시지는 겁먹지 말고 그대로 복사해서 검색하거나 AI에게 물어보기** — 저도 이렇게 해결 실마리를 찾았어요.

## 회사-집 동기화, 이렇게 연결했어요

설정을 마친 뒤 GitHub 저장소와 연결해 회사 PC와 집 PC의 작업 폴더를 동기화했습니다. 제가 이해한 흐름은 이렇게 단순해요.

| 단계 | 언제 | 하는 일 |
|---|---|---|
| clone | 처음 한 번 | GitHub의 저장소를 내 PC로 복사 |
| pull | 작업 시작 전 | 다른 PC에서 한 작업을 받아오기 |
| commit | 작업 중간중간 | 변경 내용을 '저장 기록'으로 남기기 |
| push | 작업 끝날 때 | 내 작업을 GitHub에 올리기 |

**핵심 습관: "시작할 땐 pull, 끝날 땐 push"**
이것만 지키면 회사에서 쓰던 글을 집에서 아이 재우고 그대로 이어 쓸 수 있어요.

## 자주 묻는 질문 (FAQ)

**Q1. VS Code를 설치하면 Git도 같이 설치되나요?**
아니요. VS Code와 Git은 별개 프로그램이라 Git은 따로 설치해야 해요. 설치 후 VS Code를 재시작하세요.

**Q2. `error: no action specified` 에러는 왜 나나요?**
제 경우엔 여러 줄의 명령어가 한 줄로 붙어서 입력된 게 원인이었어요. 명령어를 한 줄씩 다시 입력하니 해결됐습니다.

**Q3. 회사 PC와 집 PC에서 같은 GitHub 계정을 써도 되나요?**
네, 각 PC에서 `git config` 설정을 한 번씩 해주고 같은 저장소를 clone하면 돼요. 단, 회사 PC 사용은 사내 규정을 먼저 확인하세요.
