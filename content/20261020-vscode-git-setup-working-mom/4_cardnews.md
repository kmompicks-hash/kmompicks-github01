# 인스타그램 카드뉴스 (7장)

## 1장 · 표지 (후크)
- 메인: 46세 워킹맘, 회사 PC에서 에러 폭탄 터진 사연?
- 서브: 개발자 남편 없음 · 코딩 경험 없음
- 디자인: 노트북 앞 당황한 표정 일러스트 + 빨간 경고 아이콘, 배경 다크톤

## 2장 · 사건 발생
- 메인: "Git을 찾을 수 없습니다"
- 서브: 집에선 됐는데 회사 PC에선 안 된다고?
  VS Code와 Git은 따로 설치하는 프로그램이었어요.
- 디자인: VS Code 화면 캡처(개인정보 가림) + 물음표 말풍선

## 3장 · 에러 유발
- 메인: Git 설치 후 명령어를 붙여넣었더니…
- 서브: `error: no action specified` 💣
  회사 컴퓨터 망가뜨린 줄 알았어요.
- 디자인: 검은 터미널 배경에 빨간 에러 문구 크게

## 4장 · 원인 파악
- 메인: 범인은 '붙여넣기'였다
- 서브: 두 줄이어야 할 명령어가 한 줄로 붙어서
  Git이 "뭘 하라는 거야?" 하고 되물은 것
- 디자인: 두 줄 → 한 줄로 합쳐지는 화살표 도식

## 5장 · 해결 과정
- 메인: 해결법은 단 하나, "한 줄씩, 천천히"
- 서브:
  ① git config --global user.name "내이름" ⏎
  ② git config --global user.email "내이메일" ⏎
  ③ git config --global --list 로 확인 ✅
- 디자인: 명령어 3줄 코드 박스, 각 줄 끝 Enter 아이콘

## 6장 · 깃허브 연결 완료
- 메인: 회사 ↔ 집, 동기화 성공! 🎉
- 서브: 저장소는 비공개로 바꾸고 올리기.
  시작할 땐 pull, 끝날 땐 push.
- 디자인: 회사 PC ⇄ GitHub ⇄ 집 PC 연결 도식, 자물쇠·체크 표시

## 7장 · 저장 · 공유 · 팔로우 + 댓글 이벤트
- 메인: 나중에 또 헷갈릴 때를 위해 📌 저장!
- 서브: 부업 고민하는 친구에게 공유해 주세요.
  댓글에 **'자동화'** 남기면 설정 가이드북을 DM으로 보내드려요 📩
  46세 워킹맘의 AI 자동화 도전기, 다음 편이 궁금하면 팔로우!
- 디자인: 상단 저장(북마크)·공유(종이비행기) 아이콘, 가운데 큰 말풍선 '자동화', 하단 프로필 핸들 + 팔로우 버튼
